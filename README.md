# ckasper21.github.io

Personal portfolio site for Chris Kasper, built as a simple static GitHub Pages project.

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript

## Project structure

- `index.html` - Main single-page site markup
- `css/styles.css` - Site styling, layout, and responsive rules
- `js/main.js` - Fade-in and smooth-scroll interactions
- `img/` - Image assets

## Run locally

Because this is a static site, you can open `index.html` directly in a browser.

If you prefer serving it locally:

```bash
cd ckasper21.github.io
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

This repository is intended for GitHub Pages hosting. Push changes to the default branch for updates to the site.
